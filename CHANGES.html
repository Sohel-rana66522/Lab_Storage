Before it works

  1. Firebase Console → Authentication → Sign-in method: enable Email/Password.
  2. Deploy the rules: firebase deploy --only firestore:rules (sign-up fails with permission-denied until you do).

How it works

Each student gets a Firebase account with email <studentid>@students.labledger.app (derived from the Student ID). The profile is saved in users/{uid} with displayName, studentId, batch, role: "STUDENT", email, uid, createdAt. Login signs in by Student ID, then checks the typed name matches the saved name.

Know this

  • There is no password: anyone who knows a Student ID and the matching name can log in as that student.
  • Student IDs may use letters, numbers and - . _ only.
