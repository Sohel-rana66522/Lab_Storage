Client portal: student login, phone, order form, profile

This zip contains every file changed so far. Unzip into the project root and overwrite. Paths match the repo.

This update: student profile page

  • New page /profile (person icon in the top bar). The student can edit Name, Batch and Phone. The Student ID is shown but locked.
  • firestore.rules: a student may update only displayName, batch and phone of their own profile. ID, email and role can never change.
  • New file: lib/client/pages/client_profile_page.dart. Edited: student_auth_repository.dart (updateProfile), client_router.dart, client_shell.dart.

Deploy

  1. firebase deploy --only firestore:rules (required)
  2. Email/Password enabled in Firebase Authentication

Know this

  • Why the ID is locked: the login account is built from the Student ID. Firebase cannot change that account's email without a real email verification, and these accounts have no real mailbox.
  • If the name is changed, the student must type the new name at the next login.
  • Past orders keep the name and phone they were placed with.
