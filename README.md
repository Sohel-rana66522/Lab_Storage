# Lab Ledger

A digital version of a laboratory's chemical entry book, organized like a file manager:

📁 Folder → 📄 Chemical File → 📖 Entry History → ➕ Add Stock / Record Usage → 📊 Live balance

Built with Flutter, Dart, Cloud Firestore, Firebase Authentication and Riverpod, following
the Stitch-designed UI in `DESIGN.md` / the exported HTML screens.

See **SETUP.md** to connect it to your own Firebase project and run it.
